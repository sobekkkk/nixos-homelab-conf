## Méthode et couverture

La revue a croisé les modules Nix de pare-feu, SSH, Docker, Tailscale, privilèges et snapshot avec le rapport de baseline privé. L'évaluation Nix et la vérification de flake sans build ont réussi. La collecte Gitleaks, Trivy, Nmap et snapshot a réussi; le rapport de baseline a été validé avant revue.

Contrôles positifs : SSH effectif refuse root, mot de passe et forwarding TCP; les services sshd, Docker, la garde Docker et Tailscale sont actifs; la garde DOCKER-USER est présente en IPv4 et IPv6; sobek n'appartient pas au groupe Docker. Gitleaks et Trivy ne signalent aucun finding dans les artefacts privés.

## Findings

### F-001 — Baseline externe Windows incomplètement attestée

- Statut : confirmed (défaut de couverture du workflow, pas vulnérabilité serveur)
- Sévérité : basse; confiance : haute
- Cause : la découverte Nmap du runner SSH est exécutée depuis l'hôte audité. Elle confirme des listeners locaux mais ne prouve pas l'exposition vue depuis Windows.
- Correction appliquée : le script Windows vérifie désormais les cinq ports autorisés, au lieu de trois; le runner distant n'exécute plus Codex.
- Retest : installer Nmap sur Windows, exécuter le script Windows contre l'unique IP autorisée, puis corréler les résultats avec les preuves privées.

### F-002 — Résultat vulnix non concluant

- Statut : candidate
- Sévérité : informationnelle; confiance : haute
- Preuve : la collecte vulnix du système a terminé avec le code 2. Aucune vulnérabilité n'est déduite de ce seul code.
- Action : diagnostiquer l'outil et relancer uniquement l'inventaire de dépendances lors d'une passe ultérieure; ne pas appliquer de correctif sans finding validé.

## Limites et actions différées

La connectivité TCP directe depuis l'environnement d'exécution Windows de l'agent n'est pas une preuve fiable de l'exposition LAN; le script Nmap Windows versionné est le retest requis. Le routeur, la redirection Internet, l'IPv6 et les appareils tailnet restent hors périmètre. Toute exploitation, modification de configuration, rebuild ou redémarrage exige une approbation explicite.
